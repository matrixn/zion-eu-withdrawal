# Zion EU Withdrawal Pro

The Pro add-on is developed on `main` and extends the Free/core plugin without duplicating its legal flow or database.

## Phase 11 foundation

- Requires the active `Zion EU Withdrawal` core plugin.
- Uses the same versioned legal profile, withdrawal tables, snapshots and notification flow.
- Loads as `pro/zion-eu-withdrawal-pro.php` and can be deactivated independently.

## Phase 12 controls

- Visual floating button, placement, colors, radius, bilingual labels and controlled CSS.
- Checkout copy and placement customization, including WooCommerce Checkout Blocks compatibility through the core integration.
- Advanced indicative Rules Engine for categories, tags, product type, order status, country and shipping method.
- Delivery meta key, delivered-status fallback, deadline reminders and dashboard CSV export.
- Protected REST API and HMAC-signed webhooks.
- Agency label and white-label controls.

All Pro settings use the same AJAX autosave pattern with feedback beside the changed setting. Pro rules never block submission and do not perform automatic refunds.
